# AITUTORS-QCORE-KG-HIERARCHICAL-PILOT-01

- 日期：2026-11-26
- 性质：20 题小样本语义结构验证
- 数据：复用 full-v1 / rep2 / rep3 三次运行，不新增模型调用
- 结论：分层有效，但 Primary 稳定性仍未达 90%

---

## 1. 样本

按学科分层取 20 道已发布题：

- 数学、英语、语文、物理、化学、生物；
- 每题具有三份有效运行；
- 覆盖细粒度差异、Primary/Supporting 角色变化、上层分类收敛案例。

数据：

```text
_dsh/workpackage_c/pilot_20.json
```

---

## 2. 方法

对每次运行的 Primary 节点：

1. 用 mytutors `parent_code/level` 回溯；
2. mmlong 用 `textbooks[].chapter_path` 对齐 level=3；
3. 无上层时显式 fallback 到学科根；
4. 比较三次运行的：
   - 细粒度 Primary 集合；
   - level=3 上层分类集合；
   - 严格可解析样本的 level=3 集合。

这不是新的全量映射，也不是重新选择模型；只验证层级语义能否收敛历史差异。

---

## 3. 结果

| 指标 | 结果 |
|---|---:|
| 样本 | 20 |
| 细粒度 Primary 一致 | 10/20 = 50% |
| level=3 粗分类一致 | 16/20 = 80% |
| 严格可解析样本 | 13 |
| 严格 level=3 一致 | 11/13 = 84.6% |

对比 169 题整体：

| 指标 | 166 题整体 |
|---|---:|
| 细粒度一致 | 64/166 = 38.6% |
| level=3 粗分类一致 | 124/166 = 74.7% |
| level=3 严格样本 | 83/107 = 77.6% |

---

## 4. 结论

### 有效

- 上层化把 20 题一致率从 50% 提升到 80%；
- 把整体细粒度一致率从 38.6% 提升到 74.7%；
- 证明“Primary 负责分类稳定，Secondary 负责细粒度”方向成立。

### 不足

- 20 题 80% 仍低于 90% 门槛；
- 严格 level=3 仅 84.6%；
- 上层覆盖不足：1,970/4,829 节点无法解析 level=3；
- 59/166 题需要 fallback 到学科根；
- 42/166 题即使上移仍不一致。

因此：

```text
PILOT DIRECTION = VALID
V2 FULL MAPPING = NOT READY
```
